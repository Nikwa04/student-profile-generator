# Student Profile Generator

A Python application that requests personal data from the user and presents it in an organised format.

## Demo

Here is how the program works when you run it:

```text
\$ python app.py

Please enter your full name and surname: Jane Doe
Please enter your age: 32
Please enter your course: Psychology      
What is your favourite hobby?: Cooking
Are you a registered CUT student? [Yes/No]: Y  


==================================================
STUDENT PROFILE GENERATOR
==================================================


Name:                                 Jane Doe
Age:                                  32
Course:                               Psychology
Favourite Hobby:                      Cooking
CUT Student:                          True
```
